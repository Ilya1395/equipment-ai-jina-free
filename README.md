# Поиск характеристик оборудования: бесплатная версия Jina + Hugging Face

Проект для Streamlit Community Cloud.

## Что делает приложение

Пользователь вводит:

- Класс
- Подкласс
- Код модели

Приложение:

1. Формирует поисковые запросы по модели оборудования.
2. Ищет источники через Jina Search/Reader.
3. Читает найденные страницы в LLM-friendly формате.
4. Извлекает характеристики через бесплатный токен Hugging Face.
5. Если HF_TOKEN не указан или модель недоступна, использует резервный парсер по шаблонам.
6. Формирует таблицу:
   - Класс
   - Подкласс
   - Код модели
   - Характеристика
   - Значение
   - Ед. изм.
   - Источник
7. Позволяет скачать CSV и XLSX.

## Почему не используется Brave Search API

Brave Search API может быть недоступен как полностью бесплатный вариант для вашего аккаунта. Поэтому в этой версии поиск сделан через Jina Search/Reader.

Jina Search вызывается через URL вида:

```text
https://s.jina.ai/?q=...
```

Jina Reader для ручных ссылок вызывается через:

```text
https://r.jina.ai/https://example.com/page
```

Без ключа Jina может работать с ограничениями по частоте. Ключ Jina необязателен.

## Какие ключи нужны

Минимально:

```toml
HF_TOKEN = "hf_ВАШ_ТОКЕН"
```

Необязательно:

```toml
JINA_API_KEY = "jina_ВАШ_КЛЮЧ"
```

JINA_API_KEY не обязателен. Он нужен только для повышенных лимитов, если вы его получите.

## Как запустить в Streamlit Cloud

1. Создайте новый репозиторий GitHub.
2. Загрузите содержимое этой папки в корень репозитория.
3. Откройте https://share.streamlit.io.
4. Нажмите New app.
5. Выберите ваш репозиторий.
6. В поле Main file path укажите:

```text
app.py
```

7. В Secrets добавьте:

```toml
HF_TOKEN = "hf_ВАШ_ТОКЕН"
```

8. Нажмите Deploy.

## Как получить Hugging Face token

1. Откройте https://huggingface.co.
2. Зарегистрируйтесь или войдите.
3. Нажмите на аватар в правом верхнем углу.
4. Откройте Settings.
5. Выберите Access Tokens.
6. Нажмите New token.
7. Название: `streamlit-equipment-search`.
8. Роль: `Read`.
9. Создайте токен и скопируйте его.
10. Вставьте в Streamlit Secrets:

```toml
HF_TOKEN = "hf_xxxxxxxxxxxxxxxxxxxxxxxxx"
```

## Что делать, если ИИ не ответил

Приложение автоматически использует резервный парсер по шаблонам. Он хуже нейросети, но позволяет получить характеристики вида:

- Мощность: 4 кВт
- Масса: 120 кг
- Производительность 40 м3/ч
- Напор 25 м
